# ParsePesa SDK Ecosystem 🇰🇪💸

Welcome to the official SDK repository for **ParsePesa** - The Stripe for M-Pesa SMS. 

ParsePesa allows developers to convert raw M-Pesa confirmation messages into structured JSON in milliseconds. Build financial products, automate bookkeeping, and manage payments with ease.

## 🚀 Supported Platforms

| Platform | Package | Installation |
|----------|---------|--------------|
| **Python** | `parsepesa` | `pip install parsepesa` |
| **Node.js** | `parsepesa` | `npm install parsepesa` |
| **Flutter** | `parsepesa` | `flutter pub add parsepesa` |
| **PHP** | `parsepesa/php` | `composer require parsepesa/php` |

---

## 🛠️ Core Features
- **Instant Parsing**: Convert any M-Pesa SMS into a clean JSON object.
- **Batch Processing**: Process up to 50 messages in a single API call.
- **Balance Checks**: Programmatically check your account balance.
- **Webhooks**: Easily manage and receive payment callbacks.
- **Daraja Proxy**: Simplified bridge for Safaricom Daraja API.
