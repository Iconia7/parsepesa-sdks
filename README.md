# ParsePesa Official SDKs

Welcome to the official SDK repository for [ParsePesa](https://parsepesa.nexoracreatives.co.ke). 

ParsePesa is a high-performance API that converts raw M-Pesa SMS notifications into structured JSON data instantly. This repository contains the official clients for Python, Node.js, and Flutter.

## 🚀 Available SDKs

| Platform | Package | Installation |
|----------|---------|--------------|
| **Python** | [parsepesa](https://pypi.org/project/parsepesa/) | `pip install parsepesa` |
| **Node.js** | [parsepesa](https://www.npmjs.com/package/parsepesa) | `npm install parsepesa` |
| **Flutter** | [parsepesa](https://pub.dev/packages/parsepesa) | `flutter pub add parsepesa` |

## 🛠️ Key Features
- **SMS Parsing**: Convert M-Pesa, Till, Paybill, and Merchant messages to JSON.
- **Batch Processing**: Parse up to 50 messages in a single request.
- **Daraja Proxy**: Bridge Safaricom callbacks directly to your backend.
- **AI Fallback**: Gemini-powered parsing for non-standard message formats.
- **Account Management**: Check your balance and manage webhooks via code.
